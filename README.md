# Antigravity Fix Full Suite

Автоматический скрипт установки прокси для **десктопного Antigravity** и **Antigravity CLI (`agy`)**. Поддерживает Windows PowerShell 5.1 и PowerShell 7.

## Описание

Скрипт проверяет наличие EXE и исправляет все найденные установки. Если установлено только одно приложение, второе пропускается; если нет обоих — завершает работу без скачивания и создания пустых папок.

В [antigravity-proxy v2.4](https://github.com/yuaotian/antigravity-proxy/releases/tag/v2.4) архивы разделены на `ide` (десктопная версия) и `cli`. Для каждого приложения скрипт скачивает нужный архив последнего релиза и определяет x64/x86 по самому EXE.

| Приложение | Куда устанавливается | Файлы |
|---|---|---|
| Десктопный Antigravity | Рядом с `Antigravity.exe` или `Antigravity IDE.exe` | `version.dll`, `config.json` |
| CLI | Рядом с `agy.exe` | `dbghelp.dll`, `antigravity_proxy.dll`, `config.json` |

Автопоиск десктопной версии: папки `Antigravity` и `Antigravity IDE` внутри `%LOCALAPPDATA%\Programs`, `%ProgramFiles%`, `%ProgramFiles(x86)%`. Автопоиск CLI: `%LOCALAPPDATA%\agy\bin`, `%LOCALAPPDATA%\agy` и `agy.exe` в PATH. Проверяется наличие исполняемого файла, а не только папки.

Старые релизы с общим архивом и `version.dll` для CLI тоже поддерживаются. При переходе на новый CLI старый `version.dll` сохраняется в резервной копии и удаляется из папки `agy.exe`.

## Использование

Запустите скрипт в PowerShell:

```powershell
.\antigravity-fix.ps1
```

Перед заменой файлов скрипт закрывает процессы из папок найденных приложений, включая дочерние процессы. Сохраните работу перед запуском. Для установки в Program Files могут понадобиться права администратора.

Проверить обнаружение приложений, скачивание и содержимое архивов без изменения установок и остановки процессов:

```powershell
.\antigravity-fix.ps1 -WhatIf
```

Для нестандартных путей укажите папки с EXE. Неуказанное приложение по-прежнему ищется автоматически:

```powershell
.\antigravity-fix.ps1 -AntigravityPath 'D:\Apps\Antigravity' -AgyPath 'D:\Tools\agy\bin'
```

## Конфигурация по умолчанию

Для новой установки используется SOCKS5 `127.0.0.1:10808`. Прокси-клиент с этим адресом должен быть запущен отдельно.

Существующие настройки `config.json`, включая адрес, порт, авторизацию и правила, сохраняются. Недостающие поля берутся из конфигурации скачанного релиза. JSON записывается в UTF-8 без BOM.

Все архивы и конфигурации проверяются до изменения приложений. Перед заменой существующие файлы сохраняются в `proxy-backup-<дата>-<идентификатор>` рядом с EXE. При ошибке копирования изменения текущего приложения откатываются; успешно обновлённое ранее приложение остаётся обновлённым. Ошибки завершают скрипт с кодом 1.

Для ручного отката закройте приложение и восстановите файлы из резервной копии. При откате CLI на старую версию также удалите новый `antigravity_proxy.dll`.

## Проверка

Автономные регрессионные проверки используют временные установки и архивы, не обращаются к сети и не затрагивают установленные приложения:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\antigravity-fix.Tests.ps1
pwsh.exe -NoProfile -File .\tests\antigravity-fix.Tests.ps1
```
